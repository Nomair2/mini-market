# ADR-007: عدم تعديل أو حذف المعتمد

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
فواتير وقيود وحركات مالية لا تُحذف في أي نظام محاسبي سليم.

## القرار
الحالات draft/approved/cancelled. المعتمد غير قابل للتعديل/الحذف: مستودع + Triggers (TR-1..3). التصحيح بإلغاء وقيد عكسي ومرتجعات.

## البدائل المدروسة
الحذف مع سجل تدقيق (يفسد الأرصدة).

## النتائج
سجل كامل وقابل للتدقيق. إلغاء الشراء مشروط بتوفر الكمية والقيمة، وإلا مرتجع.
