# ADR-001: Local-first مع SQLite عبر Drift

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
المتجر يجب أن يعمل بلا إنترنت، وبهاتف واحد.

## القرار
SQLite (Drift) مصدر الحقيقة. Firebase للنسخ الاحتياطي/المزامنة الاختيارية فقط.

## البدائل المدروسة
Firebase كقاعدة رئيسية (يتطلب اتصالاً)، Hive/Isar (علاقات ومعاملات أضعف).

## النتائج
معاملات ACID حقيقية وSQL للتقارير. الاستعادة من نسخة احتياطية عبر ملف واحد.
