# ADR-011: ترقيم المستندات

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
فواتير بتسلسل بلا فجوات عند الفشل.

## القرار
`document_sequences` تُزاد داخل نفس المعاملة. صيغة `<prefix>-<6 أرقام>`.

## البدائل المدروسة
UUID كرقم (غير مقروء)، عداد في الذاكرة (يضيع).

## النتائج
إن فشلت المعاملة لا يُستهلك الرقم. جهاز واحد في V1، ويُضاف مقطع الجهاز عند تعدد الأجهزة.
