# ADR-003: معرّفات UUID v7

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
إنشاء السجلات دون اتصال، وتهيئة المزامنة لاحقاً.

## القرار
`TEXT` UUID v7 تُولَّد على الجهاز عبر `IdGenerator`.

## البدائل المدروسة
أعداد تلقائية (تتعارض عند الدمج/الاستعادة)، UUID v4 (غير مرتّب زمنياً).

## النتائج
فهارس أفضل من v4، ولا تعارض مستقبلاً. حجم أكبر قليلاً من INTEGER.
