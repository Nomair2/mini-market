# ADR-004: Money وQuantity والتقريب

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
العملة الليرة السورية بلا كسور. دقة الحساب حرجة. الليرة الجديدة (حذف صفرين) متداولة منذ 1 يناير 2026.

## القرار
`Money(minor:int)` و`Quantity(milli:int)`. النسب والتناسب بأعداد صحيحة. التقريب: لأقرب وحدة، نصف لأعلى، في سطر الفاتورة فقط. الخصم مبلغ صحيح مخزَّن. `stores.currency_minor_digits` إعداد (V1 = 0). ممنوع double/REAL.

## البدائل المدروسة
double (أخطاء تقريب)، Decimal (أبطأ وأثقل ولا حاجة)، تخزين الكسور كنص.

## النتائج
تغيير عدد الخانات لاحقاً يحتاج ترحيل بيانات (ضرب بقوة 10)، لكن الكود لا يفترض الصفر. تكلفة الوحدات الرخيصة جداً قد تفقد دقة (تُعالَج بـ ADR-005).
