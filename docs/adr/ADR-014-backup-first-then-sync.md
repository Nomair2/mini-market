# ADR-014: النسخ الاحتياطي أولاً ثم المزامنة

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
جهاز واحد: لا تعارض متعدد المصادر، والخطر الفعلي هو ضياع الهاتف.

## القرار
المرحلة 3: تصدير/استيراد ملف القاعدة محلياً (مقترح). المرحلة 4: نسخ سحابي واستعادة. المزامنة الاختيارية عبر `sync_outbox` لاحقاً.

## البدائل المدروسة
مزامنة ثنائية الاتجاه من البداية (تعقيد بلا حاجة مع جهاز واحد).

## النتائج
حماية مبكرة للبيانات. يلزم موافقة المالك على نقل التصدير المحلي إلى المرحلة 3.
