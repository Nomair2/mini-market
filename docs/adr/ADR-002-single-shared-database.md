# ADR-002: قاعدة بيانات واحدة مشتركة

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
عدة أعضاء يبنون وحدات تحتاج بيانات مشتركة وذرّية.

## القرار
ملف `nexus.db` واحد و`AppDatabase` واحد. الجداول في `core/database/tables/<module>/` بملكية موزعة ومخطط بإدارة Claude 1.

## البدائل المدروسة
قاعدة لكل وحدة (تكسر الذرّية وتكرّر البيانات).

## النتائج
المعاملة الواحدة تغطي البيع+المخزون+المحاسبة. كل تغيير مخطط يمر عبر SCR.
