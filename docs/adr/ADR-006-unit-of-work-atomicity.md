# ADR-006: UnitOfWork والعمليات الذرّية

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
البيع والشراء والمرتجعات تغيّر المخزون والقيود والمستندات معاً.

## القرار
`UnitOfWork.run` تغلّف معاملة Drift. Use Case واحد = معاملة واحدة. الواجهات المعدِّلة ترمي StateError خارج معاملة. SQLite: WAL + synchronous=FULL + foreign_keys=ON.

## البدائل المدروسة
معاملات مستقلة لكل وحدة (حالات جزئية)، أحداث غير متزامنة (تناقض مؤقت).

## النتائج
كل شيء أو لا شيء. اختبارات فشل وسط العملية إلزامية.
