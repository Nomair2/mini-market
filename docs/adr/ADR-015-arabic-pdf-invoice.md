# ADR-015: فاتورة PDF عربية ومشاركتها

- **الحالة:** مقترح — بانتظار موافقة المالك
- **التاريخ:** 2026-11-12 | **المقرِّر:** Claude 1

## السياق
قرار المالك: الفواتير PDF مع مشاركة عبر WhatsApp. التشكيل العربي في حزم PDF حساس.

## القرار
`core/pdf` (Claude 5): خطوط عربية مضمّنة، أدوات RTL. قالب الفاتورة عند Claude 3. تُولَّد الفاتورة عند الطلب من بيانات معتمدة (لا تُخزَّن). المشاركة عبر قائمة مشاركة النظام. Spike مبكر في المرحلة 1.

## البدائل المدروسة
تحويل صفحة HTML لصورة (جودة طباعة أقل)، ربط مباشر بتطبيق WhatsApp (هشّ ومحدود).

## النتائج
خطر تقني محصور بتجربة مبكرة. حجم التطبيق يزيد بالخطوط.
